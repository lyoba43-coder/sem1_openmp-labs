# Лабораторные работы по OpenMP

## Сборка (Visual Studio)
1. Открыть solution в Visual Studio.
2. Для каждого проекта: Project → Properties → C/C++ → Language →
   OpenMP Support = Yes.
3. Ctrl+Shift+B — сборка.

## Структура репозитория
- **lab1/** — ЛР1: задачи 1-3
- **lab2/** — ЛР2: задача 4
- **lab3/** — ЛР3: задача 5
- **lab4/** — ЛР4: задача 6
