# Лабораторная работа №3 (OpenMP) — Задача 5

## Сборка
1. Открыть solution в Visual Studio.
2. Для проекта: Project → Properties → C/C++ → Language → OpenMP Support = Yes.
3. Ctrl+Shift+B — сборка.

## Запуск

### Задача 5 — геометрический центр 3D-точек

Программа генерирует файл points.txt со 100 000 точками вида (i, 2i, 3i),
читает их и вычисляет геометрический центр — средние значения по x, y и z.

Реализованы две версии:
1. Параллелизм по циклу — #pragma omp parallel for reduction(+:sx,sy,sz).
2. Функциональная декомпозиция — #pragma omp parallel sections (три секции для Σx, Σy, Σz).

Выводит геометрический центр (cx, cy, cz) и время выполнения каждой версии.
