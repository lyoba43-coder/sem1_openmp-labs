# Лабораторная работа №4 (OpenMP) — Задача 6

## Сборка
1. Открыть solution в Visual Studio.
2. Для проекта: Project → Properties → C/C++ → Language → OpenMP Support = Yes.
3. Ctrl+Shift+B — сборка.

## Запуск

### Задача 6 — вычисление (Σx + Σy + Σz) / 3N

Генерирует points.txt с 100 000 точками (i, 2i, 3i), читает их
и вычисляет значение (Σx + Σy + Σz) / 3N, где N — количество точек.

Используется функциональная декомпозиция:
- три секции (#pragma omp parallel sections) считают Σx, Σy, Σz;
- глобальная переменная total накапливает общую сумму;
- доступ к ней защищён критической секцией (#pragma omp critical).

Выводит результат и время выполнения.
