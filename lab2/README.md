# Лабораторная работа №2 (OpenMP) — Задача 4

## Сборка
1. Открыть solution в Visual Studio.
2. Для проекта: Project → Properties → C/C++ → Language →
   OpenMP Support = Yes.
3. Ctrl+Shift+B — сборка.

## Запуск

### Задача 4 — перемножение матриц
task4.exe <N>
task4.exe 500

Сравнивает последовательное и параллельное (1, 2, 4, 8 потоков)
перемножение матриц C = A * B.
Выводит время каждого варианта и контрольные значения
C[0][0], C[N-1][N-1].
